# GREED ISLAND 3D — 貪婪之島

以 **Three.js + TypeScript + Vite** 打造的《HUNTER×HUNTER》貪婪之島 3D 開放世界探索與集卡遊戲。

> 線上預覽（啟用 GitHub Pages 後）：https://max-2004-123.github.io/greeeed_island/

## 主要特色

- **5× 全島大尺度開放世界與 12 座原作區域**：紫蘇樹起始點、安多奇拔、瑪莎多拉、壽富拉比、首都利梅洛、多里亞斯、愛愛、貪婪之島港、魯比克塔、布恩森鎮、山賊之村、荒地峽谷，皆採**分區延遲串流（Lazy Streaming）與距離休眠**以維持流暢幀率。
- **獨立室內空間系統**：可從壽富拉比海盜據點大門按 `E` 進入 **磊札室內排球／躲避球體育館（42m × 28m × 15m）**。
- **實體「BOOK」集卡冊與全 164 張卡片**：完整收錄指定口袋 100 張、咒語卡 40 張、自由口袋 20 張與 GM 卡 4 張（詳見 [CREDITS.md](./CREDITS.md)）。
- **雙操控模式與防穿模物理**：
  - `WASD` / 方向鍵移動、`Shift` 衝刺、`Space` 跳躍
  - **滑鼠左鍵點擊地面自動尋路**（雙擊自動衝刺）、拖曳旋轉視角、滾輪縮放
  - 支援即時地形／階梯／斜坡高度貼合、湖岸邊界與多輪防穿模碰撞
- **快捷鍵**：
  - `E`：與 NPC、商店、傳送門、卡片拾取點互動
  - `B`：開啟「BOOK」集卡冊
  - `M`：開啟全島地圖與「同行（Accompany）」傳送選單
  - `H`：返回起始之塔接待大廳

## 本機開發與建置

```bash
npm install
npm run dev
```

建置正式版：

```bash
npm run build
npm run preview
```
